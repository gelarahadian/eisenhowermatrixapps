Buat desain dan prototype aplikasi web productivity bernama **Eisenhower Todo** yang membantu pengguna menentukan prioritas tugas menggunakan **Eisenhower Matrix**.

## Tech Stack

Gunakan teknologi berikut untuk implementasi:

* **Next.js** — gunakan App Router
* **TypeScript**
* **Tailwind CSS**
* **React**
* **Lucide React** untuk icon
* Gunakan library drag-and-drop yang kompatibel dengan React/Next.js, seperti **dnd-kit**
* Gunakan komponen React yang reusable dan modular
* Gunakan responsive design dengan pendekatan mobile-first
* Tidak perlu menggunakan backend terlebih dahulu; gunakan mock/local state untuk prototype
* Struktur kode harus siap dikembangkan menjadi aplikasi full-stack di tahap berikutnya

Pastikan komponen yang membutuhkan interaksi client menggunakan `"use client"`.

---

# Konsep Utama

Aplikasi memiliki alur utama:

1. Pengguna membuat atau memasukkan daftar tugas.
2. Setiap tugas muncul sebagai task card.
3. Pengguna dapat **drag and drop task card** ke salah satu dari 4 kuadran Eisenhower Matrix.
4. Setiap kuadran memiliki arti dan tindakan berbeda.
5. Setelah tugas ditempatkan ke kuadran, aplikasi secara otomatis mengelompokkan tugas tersebut ke dalam **Todo List berdasarkan prioritas**.
6. Pengguna dapat memindahkan task antar-kuadran kapan saja dengan drag and drop.
7. Todo List harus otomatis mengikuti perubahan kuadran.

---

# Eisenhower Matrix

Gunakan matriks 2x2 dengan dua sumbu:

* Sumbu horizontal: **Urgent → Not Urgent**
* Sumbu vertikal: **Important → Not Important**

## 1. DO — Kerjakan

**Important + Urgent**

Tindakan: Selesaikan segera.

Contoh:

* Krisis mendadak
* Deadline proyek hari ini
* Masalah yang harus segera diselesaikan

## 2. SCHEDULE — Jadwalkan

**Important + Not Urgent**

Tindakan: Jadwalkan waktu untuk mengerjakannya.

Contoh:

* Perencanaan jangka panjang
* Olahraga
* Belajar
* Pengembangan diri

## 3. DELEGATE — Delegasikan

**Not Important + Urgent**

Tindakan: Delegasikan kepada orang lain jika memungkinkan.

Contoh:

* Membalas pesan biasa
* Tugas administratif
* Permintaan rutin

## 4. DELETE — Hapus

**Not Important + Not Urgent**

Tindakan: Hapus, hentikan, atau kurangi aktivitas tersebut.

Contoh:

* Distraksi
* Aktivitas tanpa hasil
* Kebiasaan membuang waktu

# Eisenhower Matrix

Buat Eisenhower Matrix besar sebagai workspace utama.

Layout:

```text
                    URGENT              NOT URGENT
                 ──────────────────────────────────

IMPORTANT       │ DO                  │ SCHEDULE
                │ Important + Urgent  │ Important + Not Urgent
                │                     │
                │ [Task Card]        │ [Task Card]
                │ [Task Card]        │ [Task Card]
                │                     │
                ├─────────────────────┼────────────────────
                │ DELEGATE            │ DELETE
NOT IMPORTANT   │ Not Important +     │ Not Important +
                │ Urgent              │ Not Urgent
                │                     │
                │ [Task Card]        │ [Task Card]
                │ [Task Card]        │ [Task Card]
```

Setiap kuadran memiliki:

* Nama kuadran
* Label prioritas
* Deskripsi singkat
* Jumlah task
* Drop zone
* Task cards
* Empty state

Matrix harus menjadi **interactive workspace**, bukan sekadar gambar atau diagram.

# Drag and Drop

Implementasikan drag and drop menggunakan **dnd-kit**.

Task harus dapat dipindahkan:

```text
Uncategorized Tasks
        ↓
      Drag
        ↓
┌──────────┬──────────┐
│   DO     │ SCHEDULE │
├──────────┼──────────┤
│ DELEGATE │  DELETE  │
└──────────┴──────────┘
```

Ketika pengguna melakukan drag:

* Task card mengikuti cursor.
* Task card memiliki visual feedback.
* Kuadran tujuan mendapatkan highlight.
* Tampilkan indikator **"Drop task here"**.
* Gunakan smooth animation.
* Setelah drop, task langsung berpindah ke kuadran.
* Update state secara instan tanpa reload halaman.

Jika task dipindahkan dari DO ke SCHEDULE, perubahan tersebut harus langsung terlihat di Todo List.

# Task Data Model

Gunakan struktur data TypeScript seperti:

```ts
type Quadrant =
  | "do"
  | "schedule"
  | "delegate"
  | "delete";

interface Task {
  id: string;
  title: string;
  description?: string;
  dueDate?: Date;
  category?: string;
  assignee?: string;
  quadrant: Quadrant | null;
  completed: boolean;
  createdAt: Date;
}
```

Gunakan React state untuk prototype.

Pisahkan logic state management dari komponen UI agar mudah dikembangkan menjadi backend/database nantinya.

# Important UX Requirement

Matrix harus menjadi **fitur utama aplikasi**.

Jangan membuat Matrix hanya sebagai visual/static diagram.

Task harus dapat:

* Dibuat
* Di-drag
* Di-drop
* Dipindahkan antar-kuadran
* Ditandai selesai
* Diedit
* Dihapus

Perubahan posisi task pada Matrix harus langsung tercermin pada Todo List.

Tujuan utama aplikasi:

> Pengguna dapat melihat semua tugasnya, menentukan prioritas secara visual melalui Eisenhower Matrix, kemudian mendapatkan Todo List yang terorganisir secara otomatis.

Buat hasil akhirnya terlihat seperti **production-ready SaaS productivity application**, bukan sekadar wireframe atau landing page.
